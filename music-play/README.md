# Music Play

Premium Jetpack Compose music player motion study with neumorphic surfaces, glass panels, Canvas-drawn vinyl art, track sheet, playlist stack, confirmation flow and an automatic looping timeline.

## Highlights

- Kotlin + Jetpack Compose only
- Single-activity, single-composition state machine
- Canvas vinyl, waveform, organic glow lines and abstract covers
- `Animatable`, `updateTransition`, `AnimatedContent`, `AnimatedVisibility`
- `graphicsLayer`, spring/tween timing, staggered list/card reveals
- Manual interactions plus automatic showcase timeline
